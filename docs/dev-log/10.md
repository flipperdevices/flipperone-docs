We're building Flipper OS, the Linux-based operating system for Flipper One. And you don't have to wait for the official release to try it out. Install Flipper OS on a supported single-board computer (SBC) and explore Flipper One UI, App Manager, and ready-made OS profiles — all before Flipper One is out. Read on to get started.

::embed[]{url="https://youtu.be/QENMEUr5oPo"}

## What you can try today

Once Flipper OS is installed, you can explore:

- **FlipCTL UI** — try the pixel-perfect UI designed for Flipper One right in your browser.
- **App Manager** — install and run apps right from FlipCTL UI. Yes, Doom already runs.
- **OS profiles** —  try five profiles (Minimal, No Graphics, TV Media Box, Router, and Desktop), clone them, and create your own.

---

## Flipper OS without Flipper One

Flipper OS is built for the **Rockchip RK3576** system-on-chip (SoC). That means it can also run on other RK3576-based SBCs already on the market. You might even own one.

![Rockchip RK3576 SoC on a single-board computer. Supported SBCs: Armsom Sige5, FireFly ROC-RK3576-PC, Luckfox Omni3576, NanoPi M5](/files/pics/dev-log/10/flipper-os-supported-boards.jpg)

SBCs that can now run Flipper OS:
    - **Armsom Sige5** - recommended
    - **Banana Pi BPI-M5 Pro**
    - **FireFly ROC-RK3576-PC**
    - **Luckfox Omni3576**

## Install Flipper OS

The easiest way to get Flipper OS on an SBC is to flash the OS image to a microSD card, then insert it into your SBC and boot it up. Once it boots, you can open FlipCTL UI in a browser on another PC or laptop connected to the same network.

:::hint{type="info"}
For alternative installation methods and detailed instructions, see the [How to install a Linux image](../cpu-software/How-to-install-linux-image.md) page.
:::

### Step 2. Erase the eMMC bootloader (optional)

All RK3576-based boards in this guide try to boot from storage in the following order: **eMMC → microSD → USB**. Even with a bootable microSD card inserted, the RK3576 tries to boot from eMMC first. To boot from the microSD card, erase the first 32 MB of the eMMC to kill its bootloader.

:::hint{type="info"}
You can skip this step if there's no bootable OS on the eMMC storage. The RK3576 will try to boot from the microSD card right away.
:::

To erase the eMMC bootloader, follow these steps:

:::::WorkflowBlock
::::WorkflowBlockItem
Boot your board from eMMC. If it doesn't run a Linux-based OS, install one on the eMMC first.
::::

::::WorkflowBlockItem
Download the [erase-emmc.sh](https://cdn.flipperzero.one/erase-emmc.sh) script to your board.
::::

::::WorkflowBlockItem
Open a terminal on the board (directly or via SSH). In the directory containing the script, run the script:

`sudo chmod +x erase-emmc.sh`
`sudo bash ./erase-emmc.sh`
::::

::::WorkflowBlockItem
Check that the script found the right eMMC storage and confirm the erasing.
::::

::::WorkflowBlockItem
Remove the microSD card and reboot the board. The OS should no longer boot.
::::

::::WorkflowBlockItem
Insert the microSD card containing Flipper OS and reboot the board.
::::

### Install apps using App Manager

App Manager lets you install apps from an online catalog adapted for the Flipper One's screen and controls. Go to **App Manager → Install** to browse available apps, select one, and press **Install**.

![Over a dozen apps already available in App Manager](/files/pics/dev-log/10/flipper-os-app-manager.jpg "Over a dozen apps already available in App Manager")

Installed apps appear in the Apps folder in the main menu, organized by category.

### Explore OS profiles

Go to **Settings → Boot Menu**. It's the same menu that appears on the Flipper One display at startup. We covered it in more detail in [Dev Log #9](9.md), and you can see it in action in the video below.

::embed[]{url="https://youtu.be/aLRK_TnJwuA"}

Each OS profile includes a root filesystem (rootfs), a Linux kernel, and a Device Tree. Think of each profile as a separate Debian installation, with its own apps, settings, data, and Linux kernel.

- **Minimal:** A minimal Linux system without desktop environment.
- **No Graphics:** A minimal system with video hardware disabled to reduce power consumption and free up system resources.
- **Desktop:** A full Debian desktop environment powered by [KDE](https://kde.org/), with Chromium, MPV (with H.264 hardware acceleration) preinstalled.
- **TV Media Box:** Automatically launches [Kodi](https://kodi.tv/) player with HDMI-CEC enabled, so you can control it using your TV remote.
- **Router:** A minimal system without a desktop environment configured as a Wi-Fi router. The ETH0 port acts as the WAN port to connect to your internet provider. The device creates a Wi-Fi access point and shares the internet connection over Wi-Fi, ETH1, and USB-C. An `iperf3` server starts automatically for network speed testing.

You can boot, clone, and customize these OS profiles. The FlipCTL web interface starts automatically in all built-in profiles, so you can control the system from your browser.
