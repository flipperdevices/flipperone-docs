Flipper One without apps is just a PCB board, a screen, and a few sensors and antennas. What makes it truly great is the whole ecosystem of apps that use all the hardware and firmware capabilities beyond our own imagination, as proven by Flipper Zero, its community of developers, and the wide range of amazing applications available in [Flipper Lab](https://lab.flipper.net/apps). In today's Dev Log, we will explore how apps will work on Flipper One and what's already available now.

## Hello, World! Flipper One edition 

As Flipper One is basically a Linux-based computer, developing apps for it is no harder than for any other Linux system, but with some caveats. In Flipper OS, an app is a Wayland client and can be written in any language that supports Wayland. FlipCTL hosts the app, while the `flipctl_app` Rust library provides the device's UI widgets, pages, and key handling. FlipCTL also supports JavaScript and Python runtimes for running scripts written in those languages.

![Hello, World app](/files/pics/dev-log/12/hello-world.png "Hello, World on Flipper One")

The simplest 'Hello, World' app source in Rust would look like this:

```rust
use flipctl_app::{text, App, Page};

struct HelloWorld;

impl App for HelloWorld {
    fn page(&self) -> Page {
        Page::detail(vec![
            text("Hello, World!"),
        ])
    }
    fn buttons(&self) -> [&str; 5] {
        ["Close", "", "", "", ""]
    }
}

flipctl_app::main!(HelloWorld);
```

## How to draw a Page

The page shown above uses `detail`. The FlipCTL framework offers several page types for different kinds of app screens:

- `detail` — Arrange rows using elements such as `pair`, `rule`, `gauge`, `text`, `choice`, and `heading`. Longer pages scroll.
- `menu` — Create a navigable list of options.
- `log` — Display scrollable lines of output.
- `canvas` — Draw a picture for the full `256 x 144 px` screen, with the status bar and soft button row covering the top and bottom parts.

Button labels are provided through the `buttons` function that the `App` implementation expects.


## Build the app 

![Full Hello app example with a counter and gauge](/files/pics/dev-log/12/hello-app-resize.gif "Hello app on Flipper One")

A compiled app needs a manifest, dependencies, and a build script. To get started, copy the [Hello app](https://github.com/flipperdevices/flipctl-slint/tree/dev/apps/hello), then build, bundle, and deploy it using the steps in the [apps documentation](https://github.com/flipperdevices/flipctl-slint/blob/dev/docs/apps.md). The `Hello app` serves as a template and reference for creating your own apps.

The Rust app is cross-compiled for Flipper One on the developer’s computer and packaged as an AppImage containing the executable, app manifest, and supporting files. The bundle is copied to `~/Apps` on the device, where FlipCTL reads its manifest and adds it to the Apps menu.

Apps can also be installed from the App Manager's catalogue, which currently points to `apps.toml` in `flipperdevices/flipctl-apps` repository. It offers to install the appropriate runtime when a script needs one.

## JS and Python

Apps can also be written as JavaScript or Python scripts using the corresponding FlipCTL runtime apps. A `Hello, World!` in Python will look like this:

```python
#!/usr/bin/env python3
# /// flipctl
# name = "Hello World"
# status = true
# ///

import flipctl

def rows():
    return [
        flipctl.text("Hello, World!"),
    ]

app = flipctl.Detail(
    rows=rows,
    buttons=["Close", "", "", "", ""],
)
app.run()

```

Save the script as `hello.fap.py` in `~/Apps`. The manifest makes it discoverable and asks FlipCTL to draw the status bar with `status = true`. Scripts require their language runtime.

## And now for something real

![Sysinfo app example on Flipper One](/files/pics/dev-log/12/sysinfo-resize.gif "Sysinfo app on Flipper One")

Hello, World! can only demonstrate the basics of Flipper One; it's a starting point. We have a few real examples already, and an obligatory Doom port as well, but it was already covered in one of the previous [Dev Logs](https://docs.flipper.net/one/dev-log/10).


- [USB Analyzer](https://github.com/flipperdevices/flipctl-slint/blob/dev/apps/Test%20Tools/usb-analyzer.fap.py): A Python app that shows information about USB ports and what is connected to them.
- [Web Browser](https://github.com/flipperdevices/flipctl-slint/tree/dev/apps/browser): A Rust app that provides a basic web browsing interface on Flipper One. It runs Chromium in the background and presents the web content through a magnifier.
- [Voice Recorder](https://github.com/flipperdevices/flipctl-slint/blob/dev/apps/recorder/src/main.rs): A Rust app that works as an example of communication with Flipper One hardware and allows you to record and play back audio.
- [Radio](https://github.com/flipperdevices/flipctl-slint/tree/dev/apps/radio): Another Rust app that lets you listen to a few hardcoded radio stations. Ready to spin some jungle? We got you covered.
- [Uptime Monitor](https://github.com/flipperdevices/flipctl-slint/blob/dev/apps/uptime.fap.js): An example of an app written in JavaScript that simply shows how long the device has been running and how hard it is working right now.
