## A home for Flipper in Linux

![tanks_example](path/to/file.jpg)

Just because you're running in desktop mode doesn't mean the Flipper One's display has to go unused. We're exploring concepts for modular dashboards that show important info on the Flipper One while you work on an external display.

[@repetren](https://github.com/repetren) has created some very cool mock-ups and you can join the discussion [on Github](https://github.com/flipperdevices/flipperone-ui/issues/27).

## Managing user data

User data on your Flipper One needs to be accessible from all OS profiles, so a portion of the filesystem must remain independent of any single profile. 

For example, if you download a video to `/home/user/Downloads` in the `Desktop` profile, you should be able to watch it later from the `TV Media Box` profile.

We're leaning towards keeping `/home/user` tied to a specific profile, with only a single shared folder, such as `/home/user/user_data`, common to all profiles.

However, this is an open question and we have not decided how to handle other volatile profile-generated data, such as caches and settings. Another layer of complexity is added when considering OTA updates and how these should interact with user or community OS profiles. Community feedback here could help discover a sensible balance. 

## Network sniffer profile

![LAN discovery (passive & active)](/files/pics/feature-lan-discovery.png)

We've added a dedicated `Network sniffer` OS profile for pass-through sniffing and network mapping. You can check it out using the [testing suite](https://github.com/flipperdevices/flipperone-testing).

## Fine grained LED control

![](/files/pics/dev-log/11/flipper-one-measures-its-power-consumption.jpg)

We've separated out the inner and outer parts of the battery logo in the power meter so you can set them independently using the `cli` command. You can also set any of the power meter LEDs to glow white.
