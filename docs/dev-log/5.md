## M.2 connector tester for R&D and mass production

As we design Flipper One, part of our job is designing the tools used to test it on the production line. In our R&D lab, we have all the time and tools to check a single device, but mass production requires tests that are reliable, fast, and inexpensive. We built a prototype module to test the Flipper One M.2 connector during mass production since there was no off-the-shelf solution that met our needs.

![Flipper One M.2 tester](/files/pics/dev-log/5/m.2-tester.png "Flipper One M.2 tester")

The tester connects to an unpowered Main Board and checks the connections between the M.2 connector pins and the components on the board by applying test voltages to each pin and verifying the electrical response. This way, we confirm there are no open circuits, shorts, or other assembly defects.

## Pixel fonts for Flipper One UI

Flipper One UI uses three pixel fonts: [HaxrCorp 4090](https://github.com/flipperdevices/flipctl-fonts/tree/dev/HaxrCorp4090-FlipCTL), [Born2bSportyV2](https://github.com/flipperdevices/flipctl-fonts/tree/dev/Born2bSportyV2-FlipCTL), and [Busy9px](https://github.com/flipperdevices/flipctl-fonts/tree/dev/Busy9px-FlipCTL). We have extended base fonts with extra glyphs and made sure everything looks neat on the Flipper One screen.
