## New way to install Flipper OS

We created **Flipper OS Installer** — a small application (less than 20 MB) that loads over USB into the RK3576's RAM and runs directly from there. It downloads Flipper OS and OS profiles from the internet over Ethernet, then installs them to the device's storage: UFS or microSD.

![](files/pics/dev-log/9/flipper-os-installer.jpg)

On Flipper One, the installation process is controlled using the built-in buttons and screen. On other supported boards, you can use an external monitor and keyboard. For detailed steps on how to install Flipper OS check out the updated [installation guide](../cpu-software/How-to-install-linux-image.md) on the Dev Portal.

![Flipper OS Installer UI](files/pics/dev-log/9/flipper-os-installer-ui.jpg "Flipper OS Installer UI")

## New boot menu

The old boot menu, based on U-boot, was relatively slow and limited. The new one is based on a full Linux system, uses Falcon Mode and is built with the FlipCTL UI framework, resulting in a cleaner UI, more features, and faster menu start.

![Old vs new boot menu](/files/pics/dev-log/9/new-vs-old-boot-menu.jpg "Old vs new boot menu")

### New features

The old boot menu only let you select an OS profile from a list. With the new boot menu, you can:

* **Boot OS profiles from UFS or microSD storage**.
* **Set a preferred (🖤) OS profile** to boot automatically on startup.
* **Clone, rename, or delete OS profiles**.
* **Reset profiles to their initial state**.
* **View OS profile details**, including storage, kernel, and more.
* **Change OS profile settings** such as the kernel and video output.

ㅤ
::embed[]{url="https://youtu.be/aLRK_TnJwuA"}

The new boot menu launches automatically when the device starts. You can also open it from a running OS in the device's menu to switch between OS profiles.

### Under the hood

The new boot menu loads faster (**3.9 sec** → **2.8 sec**) by replacing U-Boot with a full Linux kernel with a minimal initramfs, which uses the hardware more efficiently and skips some of U-Boot's slow boot steps. It also preloads the selected OS profile's kernel into RAM while you're in the boot menu, speeding up OS booting.

### Booting the OS profile

Once you select an OS profile, it starts booting. Since Falcon is also Linux, we need a way to boot another Linux system from an already running one. We have two options:

* **kexec method (universal, but slower)** loads the OS kernel into RAM and reboots without clearing RAM. It works regardless of the loaded kernel and Device Tree.

* **pivot method (faster, but not always available)** works similarly, but skips reloading the kernel and drivers. It only works when switching between OS profiles with the same kernel and Device Tree.

## Power Meter emulator

Flipper One includes a Power Meter that shows the charging status, power coming from the charger, and power being drawn from the battery.

We've made a [Power Meter emulator](https://dev.repetren.com/power_meter_demo/) — you can try it out right in your browser and test different scenarios. We'd love to hear what you think in the comments below.

![Power Meter emulator UI in the browser](/files/pics/dev-log/9/flipper-one-power-meter-emulator.jpg "Power Meter emulator UI in the browser")
