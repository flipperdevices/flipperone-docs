## Description

Flipper One can expose storage to other devices either as a direct-attached USB mass storage device (DAS) or as a network file server (NAS). Storage sources include Flipper One's internal storage, a microSD card, a single USB-attached drive, multiple drives connected via a USB hub, or remote network shares already mapped on Flipper One. Any combination of these can be aggregated, filtered and re-shared.

## Status

Possible using Flipper One.

## User story

I want to serve files to whatever machine or network I'm connected to without disrupting tasks I’ve already got my Flipper doing to files on the drives. Other times I'm on a a network and want any device on it to reach the same storage as my Flipper even though my Flipper is accessing those files through a seperate network. I can also plug a USB hub into Flipper One, attach several drives, and share them all as separate volumes simultaneously. If I've already mapped a remote network share into Flipper One I can re-export that over USB or the local network as well, making Flipper One a universal storage bridge between sources and devices regardless of protocol.
